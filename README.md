# A Benchmark Dataset and Novel Methods for Parallax-Based Flying Aircraft Detection in Sentinel-2 Imagery

## Instruction
We construct a flying aircraft detection dataset (S2Aircraft) based on Sentinel-2 satellite multispectral imagery with a spatial resolution of 10 m.
